# 🤖 Lumina IA Generativa

Aplicativo mobile desenvolvido em React Native que utiliza a API da OpenAI para fornecer respostas inteligentes em tempo real. O projeto permite que o usuário interaja com uma inteligência artificial por meio de uma interface simples e intuitiva.

## 🚀 Funcionalidades

- Conversa em tempo real com Inteligência Artificial.
- Envio de perguntas e recebimento de respostas instantâneas.
- Interface moderna e fácil de utilizar.
- Comunicação com a API da OpenAI.
- Histórico das conversas durante o uso do aplicativo.

## 🛠️ Tecnologias utilizadas

- React Native
- JavaScript
- Node.js
- Express
- OpenAI API
- Axios

## 🎯 Objetivo

O objetivo deste projeto foi aprofundar os conhecimentos em desenvolvimento mobile, consumo de APIs REST, integração com Inteligência Artificial e comunicação entre aplicativo e servidor.

## 📱 Como funciona

1. O usuário digita uma pergunta.
2. O aplicativo envia a solicitação para um servidor Node.js.
3. O servidor realiza a comunicação com a API da OpenAI.
4. A resposta é processada e exibida na tela do aplicativo.

## 📚 Aprendizados

Durante o desenvolvimento foram aplicados conceitos de:

- Desenvolvimento Mobile com React Native.
- Consumo de APIs REST.
- Integração com Inteligência Artificial.
- Comunicação cliente-servidor.
- Manipulação de requisições HTTP.
